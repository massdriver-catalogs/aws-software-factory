# Changelog

## 0.0.0

- First release.

- Terminal access through a role assumed from your own AWS sign-in, limited to the identities in **Who can connect**. No access key is made.

- GitHub access through the GitHub App: git and gh mint short-lived installation tokens; commit name and email are fields.
- Browser access: opencode web and an app preview over HTTPS through CloudFront, behind a password. Needs Private network mode.
